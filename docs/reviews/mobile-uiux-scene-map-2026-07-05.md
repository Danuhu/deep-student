> 方法：4 路并行代码调研（全局壳层 / ChatV2 / Learning Hub / 待办·技能·制卡·模板），

## 一、总场景树（导航层）

```mermaid
flowchart TD
    ROOT[App 壳层<br/>UnifiedMobileHeader + ViewLayer]

    ROOT --> ONBOARD[首次启动<br/>协议弹窗 → Welcome Onboarding]
    ONBOARD -->|去配置 AI| SETTINGS
    ONBOARD -->|先随便看看| CHAT

    ROOT --> DRAWER[各页统一抽屉<br/>页内区 + 应用导航 8 项]
    DRAWER --> CHAT[chat-v2 新会话]
    DRAWER --> LH[learning-hub 学习资源]
    DRAWER --> TODO[todo 待办]
    DRAWER --> SKILLS[skills-management 技能管理]
    DRAWER --> TASK[task-dashboard 制卡任务]
    DRAWER --> TPL[template-management 模板管理]
    DRAWER --> SETTINGS[settings 全屏 Sheet<br/>不切 view]
    DRAWER --> CMDK[搜索与命令 → 命令面板]

    CMDK -.->|nav 命令| DASH[dashboard 总览]
    CMDK -.->|nav 命令| DATA[data-management 数据管理]
    CMDK -.->|nav 命令| PDFV[pdf-reader]
    CHAT -.->|CodeBlock 沙箱| SANDBOX[sandbox-workbench]
    TPL -.->|JSON 预览| TJP[template-json-preview]

    subgraph 三屏页面
        CHAT --- CHAT_L[左: 会话抽屉] & CHAT_R[右: 资源库/沙箱/应用面板]
        LH --- LH_L[左: DstuAppLauncher] & LH_R[右: TabBar + 预览面板]
        SKILLS --- SK_R[右: 技能编辑器]
        TPL --- TPL_R[右: 代码编辑器 仅 isCodeMode]
    end

    subgraph 两屏页面
        TODO --- TODO_L[左: TodoSidebar]
        TASK --- TASK_L[左: 标签 + 应用导航]
    end

    ROOT --> SYS[系统级<br/>Android back / 手势 / DEV FAB / 通知 / ErrorBoundary]
```

关键机制（走查时须验证的全局行为）：

- **视图保活**：touch 设备 LRU 上限 4 个非 pinned 视图；被逐出的视图再进入时状态可能丢失。
- **返回键优先级**：overlay（Dialog/命令面板/抽屉/图片查看器）→ 页面历史 → 应用退后台。
- **手势**：三屏页边缘 20px 起手、位移 30% 或 fling 切屏；PDF/编辑器/导图区域豁免。
- **设置**：移动端是全屏 Sheet，`currentView` 不变——顶栏仍显示底层页配置。
