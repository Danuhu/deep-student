# 快速上手

> 从安装到跑通"导入资料 → 带资料提问 → 生成学习产物"的核心闭环，大约需要 10 分钟。

## 第 0 步：安装

前往 [官网](https://deepstudent.cn) 或 [GitHub Releases](https://github.com/helixnow/deep-student/releases/latest) 下载对应平台的安装包：

- **桌面端**：Windows / macOS / Linux
- **移动端**：Android（APK）

安装后首次启动，所有数据默认保存在本机，无需注册账号。

## 第 1 步：配好第一把"钥匙"（模型 API）

Deep Student 本身不内置 AI 模型，需要先配置一家模型供应商的 API 密钥：

1. 打开「设置」→「模型服务」。
2. 从预置供应商中选择一家（如 SiliconFlow、DeepSeek、智谱AI、月之暗面等），填入你申请的 API 密钥。
3. 点击「测试连接」确认可用。
4. 前往「设置」→「模型分配」，至少配置好「对话模型」；如果之后要用知识库问答，还需配置「嵌入模型」。

> 💡 推荐新手使用 **SiliconFlow**：配置密钥后可使用"一键分配"，一步配齐对话、嵌入、OCR、语音等全部功能所需的模型。详见 [模型与供应商配置](./14-模型与供应商配置.md)。

## 第 2 步：发出第一条消息

1. 回到主界面（默认就是对话页），点击「新建会话」。
2. 在底部输入框输入任意问题，按 `Enter` 发送。
3. 看到 AI 正常回复，说明模型配置成功。

如果发送按钮是灰色的或提示"当前会话尚未就绪"，回到第 1 步检查「模型分配」。

## 第 3 步：导入第一份学习资料

1. 打开左侧导航的「学习资源」。
2. 直接把一份 PDF 教材**拖进窗口**，或点击「＋」→「导入教材」选择文件。
3. 导入后资料会自动进入向量化队列（OCR → 分块 → 索引），在左侧「向量化状态」中可以看到进度；等它变为「已索引」，这份资料就可以被 AI 检索了。

详见 [学习资源中心](./04-学习资源中心.md)。

## 第 4 步：带着资料提问

两种方式，任选其一：

**方式 A —— 边读边问：**

1. 在学习资源中双击打开刚导入的 PDF。
2. 点击阅读器工具栏的「选择此页」，勾选一两页。
3. 回到对话输入问题发送，AI 的回答会带页码引用，点击引用可跳回原文。

**方式 B —— 引用资源库：**

1. 在对话输入栏点击「＋」菜单 →「添加文件」→「资源库」。
2. 勾选要引用的教材或笔记，发送问题即可。

也可以直接把图片、PDF 拖进对话窗口作为附件提问。详见 [AI对话与会话管理](./02-AI对话与会话管理.md)。

## 第 5 步：生成你的第一个学习产物

试试用一句话让 AI 产出结构化的学习材料：

- **知识导图**：在对话中说"帮我生成 ×× 的知识导图"，点击回复中的导图链接即可打开编辑。详见 [知识导图](./08-知识导图.md)。
- **Anki 卡片**：说"把这份 PDF 的重点做成 Anki 卡片"，逐张检查生成的卡片后「加入卡片库」。详见 [Anki制卡与模板](./12-Anki制卡与模板.md)。
- **题目集**：说"根据这份资料出 10 道选择题"，AI 会自动创建题目集，随后可到题库中开始练习。详见 [题库与练习](./11-题库与练习.md)。

## 第 6 步（建议）：认识权限开关，做一次备份

- **权限三档**：输入栏「＋」菜单的「模式」子菜单控制 AI 能做多少事——开启「问一问」为只读回答，开启「想一想」为先确认计划再执行，两者都不开即默认的"做一做"（按审批策略直接执行）。看到「工具执行确认」卡片时按需选择允许或拒绝即可。详见 [AI对话与会话管理](./02-AI对话与会话管理.md)。
- **备份**：打开「设置」→「数据治理」→「备份」，做一次「完整备份」，并建议开启自动备份。详见 [数据管理与云同步](./16-数据管理与云同步.md)。

## 📱 移动端说明

移动端（Android）的上手流程完全相同，入口略有差异：

- 点左上角 **☰** 或从屏幕左缘右滑打开抽屉，抽屉下半部分是应用导航（新会话 / 学习资源 / 待办 / 设置等）。
- 「设置」是两级导航页面：先在分组列表首页选分区，再进入具体设置，可用顶部搜索框直接搜设置项。
- 对话中的「＋」菜单额外提供「拍照」入口，可以直接拍教材、拍题目。

完整的移动端操作与功能差异见 [移动端指南](./17-移动端指南.md)。
