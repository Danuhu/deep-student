# Plan 07-01: DeepStudent Migration Foundation

<objective>
Establish the parent DeepStudent app's first migration foundation from `study-ui`: semantic token bridge parity, one shared button primitive contract, 44px touch density through tablet, tokenized mobile shell controls, and focused regression gates for hard-coded colors and forbidden motion.
</objective>

<scope>
This plan targets the parent app `src/` foundation only. It does not rewrite product pages, replace every raw button, or migrate every Lucide icon. Legacy surfaces may remain as-is until their owning migration phase.
</scope>

<tasks>

1. **RED source guard**
   - Type: test
   - Files: `src/components/ui/__tests__/migrationFoundation.source.test.ts`
   - Action: Add a focused Vitest source/static guard that checks required token aliases, shared primitive import usage, 44px touch sizing, color/motion bans in migrated files, and icon governance for the selected shell primitives.
   - Verify: Run the new test before implementation and confirm it fails on the current split primitives and mobile shell violations.
   - Acceptance criteria: The failure is due to missing Phase 7 guarantees, not test syntax or environment setup.

2. **Token bridge parity**
   - Type: implementation
   - Files: `src/styles/shadcn-variables.css`, `src/styles/theme-colors.css`
   - Action: Add the missing `study-ui` button/density aliases once in token files: `--button-height*`, `--button-padding-x*`, tonal/outline/destructive button tokens, and preserve `--touch-target-size` as the canonical below-`lg` sizing token.
   - Verify: The RED token guard passes for token family presence.
   - Acceptance criteria: Component code can consume semantic button/input/shell tokens without inventing local palettes.

3. **Shared primitive contract**
   - Type: implementation
   - Files: `src/components/ui/buttonPrimitiveContract.ts`, `src/components/ui/NotionButton.tsx`, `src/components/ui/shad/Button.tsx`, `src/components/ui/shad/Button.css`, `src/components/ui/shad/Input.tsx`, `src/components/ui/shad/Switch.tsx`
   - Action: Extract the shared `study-ui`-style base, tone, size, icon, shell nav, and shell icon-button class maps. Make both `NotionButton` and `ui/shad/Button` consume it, remove inline pixel min-height fallbacks, and make input/switch satisfy 44px touch density below `lg`.
   - Verify: Source guard proves both button facades import the same contract and sizes compact only at `lg`.
   - Acceptance criteria: `NotionButton` and `Button` are no longer separate behavioral contracts; migrated controls use `h-[var(--touch-target-size)]` below `lg`.

4. **Mobile shell tokenization**
   - Type: implementation
   - Files: `src/components/layout/MobileHeader.tsx`, `src/components/layout/UnifiedMobileHeader.tsx`, `src/components/layout/MobileSidebarNavigation.tsx`, `src/components/ui/unified-sidebar/MobileSidebarLayout.tsx`, `src/components/ui/unified-sidebar/SidebarDrawer.tsx`, `src/components/ui/unified-sidebar/UnifiedSidebar.tsx`
   - Action: Replace local hard-coded shell button palettes and sub-44px touch classes with shared token class maps. Keep structural drawer transforms, but remove button-local hard-coded colors, `shadow-black/*`, `bg-card/85`, `md:` shrink, and `minHeight: 36` from migrated shell controls.
   - Verify: Source guard passes color, touch, motion, and icon checks over the targeted migrated files.
   - Acceptance criteria: Mobile header/sidebar/sheet close controls use semantic tokens and remain 44x44 until `lg`.

5. **Verification and GSD tracking**
   - Type: verification
   - Files: `study-ui/.planning/phases/07-deepstudent-migration-foundation/07-01-SUMMARY.md`, `study-ui/.planning/ROADMAP.md`, `study-ui/.planning/REQUIREMENTS.md`, `study-ui/.planning/STATE.md`
   - Action: Run targeted Vitest, targeted ESLint, `git diff --check`, and a Vite build. Start the local dev server for manual visual inspection URL. Record outcomes and any residual manual-check gaps.
   - Verify: Command results are captured in the summary artifact.
   - Acceptance criteria: Automated gates pass or any remaining blockers are clearly documented before claiming completion.

</tasks>

- Parent token bridge exposes `study-ui` button, input, shell, sidebar, focus, destructive, and touch-density aliases from token files.

- `NotionButton`, `ui/shad/Button`, `Input`, `Switch`, mobile header buttons, sidebar nav rows, and sheet/drawer close controls preserve 44px touch targets below `lg`.
- Target migrated files reject component-local hard-coded colors, RGBA shadows, decorative gradients, `md:` primitive compaction, `active:scale`, and spring motion.
- Phase tracking artifacts identify Phase 7 as executed with automated verification evidence and any remaining manual visual checks.
