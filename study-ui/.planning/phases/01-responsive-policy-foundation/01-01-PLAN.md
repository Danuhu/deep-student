# Plan 01: Responsive Policy Foundation

<objective>
Create the Phase 1 responsive policy foundation: one tested environment model, one tested layout policy, and a minimal `AppChrome` integration that removes the local `max-width: 767px` compact decision without changing visible shell behavior.
</objective>

<threat_model>
## Threat Model

### T-01: Desktop Shell Regression
- **Severity:** medium
- **Risk:** Moving responsive logic could accidentally alter desktop docked sidebar, macOS traffic-light accessory, Windows controls, or resize handles.
- **Mitigation:** Keep Phase 1 limited to decision-source migration. Do not alter `Titlebar`, `Sidebar`, `WindowControls`, or `FramelessResizeHandles`. Run `src/components/shell/AppChrome.source.test.ts` and `src/lib/app-shell.test.ts`.

### T-02: Breakpoint Drift
- **Severity:** medium
- **Risk:** JS modules, source tests, and future CSS tokens could use different breakpoint values.
- **Mitigation:** Put breakpoint numbers only in `src/lib/responsive-env.ts` and assert `639`, `640`, `767`, `768`, `1023`, and `1024` in `src/lib/responsive-env.test.ts`.

### T-03: SSR/Test Runtime Crash
- **Severity:** low
- **Risk:** Browser-only APIs could run when `window` is unavailable.
- **Mitigation:** Provide `getServerResponsiveEnvironment()` and keep `useSyncExternalStore` server snapshot safe.
</threat_model>

      Create `src/lib/app-layout-policy.ts` with this concrete API:

      ```ts
      import type { FormFactor, InputMode, ResponsiveEnvironment, ShellMode } from "./responsive-env.ts";

      export type SidebarMode = "drawer" | "docked";
      export type Density = "touch" | "desktop";

      export type AppLayoutPolicy = {
        formFactor: FormFactor;
        isCompact: boolean;
        inputMode: InputMode;
        shellMode: ShellMode;
        sidebarMode: SidebarMode;
        density: Density;
      };

      export function getAppLayoutPolicy(environment: ResponsiveEnvironment): AppLayoutPolicy {
        return {
          formFactor: environment.formFactor,
          isCompact: environment.isCompact,
          inputMode: environment.inputMode,
          shellMode: environment.shellMode,
          sidebarMode: environment.isCompact ? "drawer" : "docked",
          density: environment.isCompact || environment.inputMode === "coarse" ? "touch" : "desktop",
        };
      }
      ```

      Create `src/lib/app-layout-policy.test.ts` with tests for:

      - desktop `1280/coarse` maps to `sidebarMode: "docked"` and `density: "touch"`.
      - policy preserves `formFactor`, `isCompact`, `inputMode`, and `shellMode` from the environment.
