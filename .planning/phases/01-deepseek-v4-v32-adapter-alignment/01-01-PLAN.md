## Goal

Make DeepSeek model capability detection version-aware and provider-aware enough that V4 resolves to 1,000,000 context tokens while current SiliconFlow V3.2 remains 128,000.

5. Add tests proving V4 context is 1,000,000 and V3.2 context remains 128,000.
